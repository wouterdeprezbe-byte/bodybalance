# Body Balance Intake

Statische pagina voor The Next Level Health Project. Klanten vullen de vragenlijst in en krijgen een bedankje. De antwoorden gaan naar een Google Apps Script van de coach, dat de score berekent en het rapport mailt.

- `config.js` – verzendadres (Apps Script-URL), naam van de coach, links
- `assets/` – vragenlijst, opmaak en lettertypes (lokaal, geen Google Fonts)

De weging van de score staat niet in deze repository: die zit enkel in het Apps Script.
